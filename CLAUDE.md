# Working in TYPO3 documentation repositories

See [AGENTS.md](AGENTS.md) for the shared conventions across TYPO3
documentation repositories (content style, git workflow, committing). This
file exists only because Claude Code specifically looks for `CLAUDE.md`;
the content itself is tool-agnostic and lives in `AGENTS.md`.

One Claude-specific detail: in the commit message trailer format described
in AGENTS.md, use `Assisted-by: Claude <model name> <noreply@anthropic.com>`
— the actual model name you're running as, not a guess.
