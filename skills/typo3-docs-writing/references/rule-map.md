# Which page holds the rule

Paths are relative to the root of the guide repository. The anchor is the
`..  _anchor:` target to search for. An anchor of the guide never goes
away, so a search for it always finds the current section, even after the
page has moved.

Read the page for every kind of content that your text contains.
